# Timi Odusanya

Personal site for Timilehin “Timi” Odusanya, Senior Full Stack Engineer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js, React, TypeScript, Tailwind CSS, Motion.

Content lives in `data/`. Add a project or automation system there - the UI is driven by those types.
